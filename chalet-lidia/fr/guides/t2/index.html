Trouvez votre Lodge
  • après le portail principal, tournez à gauche puis descendez les escaliers.
  • en bas, vous verrez 2 portes vitrées ; la vôtre se trouve à droite.
  • pour accéder à votre lodge, saisissez le même code que pour le portail principal (appuyez de nouveau sur # à la fin)
  • à chaque chiffre saisi, un petit voyant vert s'allume dans le coin supérieur droit
  • si le code est correct, le petit voyant vert clignote et vous entendrez la serrure se déverrouiller (veuillez attendre la fin)
  • une fois déverrouillée, tournez la poignée dans le sens inverse des aiguilles d'une montre jusqu'à la position verticale, puis poussez la porte vers l'intérieur et faites-la coulisser vers la droite.

Règlement intérieur, accès wifi et horaires d'arrivée/de départ pour un séjour sans souci.

Verrouiller de l'extérieur
  • fermez la porte en la faisant coulisser vers la droite et tirez la poignée vers vous
  • puis tournez la poignée dans le sens inverse des aiguilles d'une montre jusqu'à ce qu'elle pointe vers le bas
  • appuyez sur le bouton # (en bas à droite) pendant 3 à 4 secondes jusqu'à entendre le bruit du verrou

 

Verrouiller de l'intérieur
  • fermez la porte en la faisant coulisser vers la droite et poussez-la devant vous
  • puis tournez la poignée dans le sens inverse des aiguilles d'une montre jusqu'à ce qu'elle pointe vers la droite
  • enfin, appuyez sur le bouton situé sur la face de la serrure connectée — elle tournera automatiquement et verrouillera la poignée

 

Déverrouiller de l'extérieur
  • pour accéder à votre lodge, saisissez votre code d'accès et terminez avec le bouton # (en bas à droite)
  • à chaque chiffre saisi, un petit voyant vert s'allume dans le coin supérieur droit
  • si le code est correct, le petit voyant vert clignote et vous entendrez la serrure se déverrouiller
  • une fois déverrouillée, tournez la poignée dans le sens des aiguilles d'une montre jusqu'à ce qu'elle pointe vers le haut, puis poussez la porte vers l'intérieur et faites-la coulisser vers la droite.

 

Déverrouiller de l'intérieur
  • appuyez sur le bouton situé sur la face de la serrure connectée
  • elle tournera automatiquement et déverrouillera la poignée 
  • tournez la poignée dans le sens des aiguilles d'une montre, jusqu'à ce qu'elle pointe vers la gauche
  • tirez la porte vers vous puis faites-la coulisser vers la gauche pour l'ouvrir

Canapé-lit
