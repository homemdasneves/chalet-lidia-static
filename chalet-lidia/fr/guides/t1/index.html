Tout ce qu'il faut pour nous trouver, vous garer à proximité et entrer sans difficulté.

Trouvez votre Lodge
  • après le portail principal, tournez à gauche puis descendez les escaliers.
  • en bas, vous verrez 2 portes vitrées ; le lodge suite se trouve à gauche.
  • pour accéder à votre lodge, saisissez le même code que pour le portail principal (appuyez de nouveau sur # à la fin)
  • à chaque chiffre saisi, un petit voyant vert s'allume dans le coin supérieur droit
  • si le code est correct, le petit voyant vert clignote et vous entendrez la serrure se déverrouiller (veuillez attendre la fin)
  • une fois déverrouillée, tournez la poignée vers la gauche et vers le haut jusqu'à ce qu'elle soit en position verticale, puis poussez la porte vers l'intérieur et faites-la coulisser vers la gauche.

Règlement intérieur, accès wifi et horaires d'arrivée/de départ pour un séjour sans souci.

Verrouiller de l'extérieur
  • il suffit de fermer la porte, la poignée se verrouille automatiquement

 

Déverrouiller de l'extérieur
  • saisissez votre code d'accès et terminez avec le bouton #
  • vous devriez entendre "unlocked"
  • vous pouvez utiliser la poignée pour ouvrir la porte 

 

Fermer les volets occultants
  • une télécommande est accrochée au mur entre les chambres
  • appuyez vers le bas pour fermer et vers le haut pour ouvrir
  • vous pouvez commander les deux volets ensemble ou chacun séparément, en appuyant sur le bouton en bas de la télécommande (avec un tiret "—")
